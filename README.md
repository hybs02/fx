# ドル円シグナル

ドル円（USD/JPY）の RSI を自動で計算し、決めた規則に当たったら「サイン」としてスマホに出す個人用ツール。
DMM FX で手で取引する前提で、入る時刻・損切りの値・数量・手仕舞う時刻・スワップの目安を表示する。API キーは要らない。

画面: https://hybs02.github.io/fx/ （開いて「ホーム画面に追加」）

売買を勧めるものではない。下の成績は過去データでの検証で、この先の成績を示すものではない。必ず勝てる方法は無く、使うかどうかは自分で判断する。

## 使い方

| やること | 方法 |
| --- | --- |
| 見る | 上の画面を開く。自動で判定し直した結果が出る |
| 今すぐ計算し直す | GitHub の Actions タブ →「update-signals」→ Run workflow |
| 手元で計算する | `python build.py`（標準ライブラリだけで動く） |
| 手元で保存データから作る | `python build.py --cache`（`research/cache/` を使う・動作確認用） |
| 相場の状況・発表日程・介入警戒の水準を直す | `fundamentals.json` を手で書き換えて main に push |
| 日銀が政策金利を変えた | `logic.py` の `BOJ_RATE` に1行足す（スワップの計算に使う） |
| PC から毎時起動する | タスクスケジューラの「usdjpy-signal-update」が毎時5分に `tools\kick_update.vbs` を呼び、`gh workflow run` で計算を始める（下） |

## 規則

| 項目 | 内容 |
| --- | --- |
| サイン | RSI(14) が 30 以下に入った最初の時刻を買い、70 以上に入った最初の時刻を売りとする。1時間ごとに「その時刻で締めた日足（24時間ごと）」で判定 |
| 同じ山 | 同じ向きの越えが5日以内にあった時は、新しいサインにしない |
| 入る時刻 | サインから3時間以内が目安、8時間を過ぎたら見送り。早朝5〜9時はスプレッドが広いので、締め切りに間に合えば9時を待つ。DMM の取引時間外（土曜 5:50〜月曜 7:00）のサインは入らない |
| 損切り | 入った値から ATR(14)×4 の逆指値。利確は置かない |
| 手仕舞い | 入った時刻の1週間後。取引時間外に当たる時は、その前で最後に取引できる時刻 |
| 持つ数 | 1つだけ |
| 介入警戒 | 160 円の手前 2 円（158 円）から上では買いのサインを止める（`fundamentals.json` の `pairAlerts`）。売りは止めない |
| 数量 | 損切りに届いた時の損が「資金×リスク%」に収まる Lot。1Lot で収まらなければミニ（USM/JPY・1Lot＝1,000通貨） |

値は `logic.py`（`BUY_AT`・`SELL_AT`・`SL_ATR`・`HOLD`・`ENTRY_BEST_H`・`ENTRY_LIMIT_H`）にあり、画面は data.json の `rule` から読む。

## しくみ

```
GitHub Actions（毎時 3・23・43 分に頼む／日〜金 UTC）
  └ build.py が Yahoo からドル円の 1時間足（730 日）・日足（2004 年〜）と米 13 週国債の利回りを取る
      └ いまの値でサイン・損切り幅・次の1時間のサイン価格・スワップの目安・検証成績を計算して data.json を作る
          └ data.json は「data」枝に毎回上書き（force push）
              └ 画面は raw.githubusercontent.com/hybs02/fx/data/data.json を読んで表示するだけ
```

- GitHub の定時実行は混んでいると遅れたり飛ばされたりし、実際に動くのは3〜7時間おきのことが多い。そのため PC のタスクスケジューラからも毎時5分に起動する（`tools/kick_update.vbs`）。PC が動いている間だけ効き、DMM が閉まっている土曜6時〜月曜6時は起動しない。結果は `tools/kick.log` に1行ずつ残る（gh=0 なら起動できた）。
- 画面は最後の計算から3時間で注意、8時間で警告を出す。
- 値が取れなかった時は build.py が止まり、data 枝の前回の結果がそのまま残る。
- data.json を main に置かない（頻繁にコミットすると main の履歴が膨らみ続ける）。

## 検証（research/）

`python research/fetch.py USDJPY` で `research/cache/` にデータを取ってから各スクリプトを実行する（引数なしなら 11 ペアすべて）。

| スクリプト | 中身 |
| --- | --- |
| `fetch.py` | Yahoo の日足・60分足・米 13 週国債の利回り、ECB の参照レートを取る |
| `common.py` | キャッシュの読み込みと集計 |
| `study_usdjpy.py` | ドル円の規則を選ぶ（下の表の数字はここから） |
| `study_baseline.py` | 朝9時締めに並べ直した日足で、点数型の判定を22年分測る（11ペア） |
| `study_search.py` | 5つの型 × 出口の組み合わせから、どの時代でも崩れない型を選ぶ（11ペア） |
| `check_js.py` / `legacy_logic.py` / `legacy_index_20260908.html` | 点数型の判定の JS 版と Python 版が一致するか（比較用） |

### 規則を決めた根拠

| 決めたこと | 根拠 |
| --- | --- |
| 日足は「朝9時締め」に並べ直して使う（`logic.make_bars`） | Yahoo の為替日足は 2010 年 6 月ごろから、終値が「その日の UTC 0 時＝日本の朝9時の値」で、高値・安値はその日1日ぶん。そのまま使うと入った日の値動きを飛ばし、その日の値幅を先読みする |
| RSI の行きすぎで逆張りする型 | 11 ペアで、採点・RSI・RSI(2)・高値安値ブレイク・モメンタムの5つの型と出口の組み合わせ 800 通りを 2004〜2018 年だけで比べ、時代ごとの一番悪い PF で選ぶと RSI 型が残った。点数型（RSI・ボリンジャー・移動平均・MACD）は22年通算 PF1.03（`study_search.py`） |
| しきい値と出口はドル円だけで選び直す | RSI 25/75・損切り×3（11 ペアをまとめて選ぶと出てくる設定）をドル円だけで測ると、22年で57回・PF1.32 だが、2011〜14年と直近5年は PF0.4 前後の負け。売りが PF0.48 |
| RSI 30/70・ATR×4・1週間 | しきい値 20〜35 × 損切り 2〜4 × 期限 3〜10 日の 48 通りを 2004〜2018 年だけで比べ（設計期間の取引が40回以上のもの）、時代ごとの一番悪い PF が最も高かった。選ぶのに使っていない 2019 年以降は PF1.88（50回）。RSI 30/70 の周りの 12 通りは 2019 年以降すべて勝ち越し（PF1.43〜1.88） |
| 損切りは ATR×4 と広め | 22年で一度も届いていない（一番大きい負けは −2.9%）。介入などの急変への保険。×3 だと 8%、×2 だと 24% が損切りで終わり、成績が下がる |
| 両方向とも使う | ドル円は売りが弱い（買い PF3.68・売り PF1.27）が、売りも22年通算で勝ち越し。片方だけにすると回数が減り、円高の局面で何もできない |
| 200日線の向きで絞らない・順張りにしない | 200日線と同じ向きだけにするとサインがほぼ消える。20日・55日の高値安値ブレイクはドル円でも PF0.8〜1.07 |
| スワップは成績に入れるが判定には使わない | 日米の金利差を日割りで足した（米 13 週国債 − 日銀の政策金利。DMM の値とほぼ同じ）。1週間では1回あたり買い +0.035%・売り −0.037% で、選ぶ設定は変わらない |
| 入るのは3時間以内、8時間で締め切り | ドル円の1時間ごとの判定（約2年・19回）では、24時間遅れても PF1.6 前後で大きくは崩れなかった。回数が少なく確かでないので早めに入る |
| 判定の時刻を固定しない | 1時間ごとに「その時刻で締めた日足」で判定する。いつ開いても最新で、朝9時の日足と同じ規則を時刻をずらして当てているだけ |

1時間足の大きな足（2024-04-29・05-01 の介入、2025-04-09 の関税停止など）は実際の出来事で、データの誤りではない。

### 成績（過去データ・スプレッド 0.2銭とスワップ込み）

朝9時締めの日足（2005〜2026）:

| 期間 | 回数 | 勝率 | 1回平均 | PF |
| --- | --- | --- | --- | --- |
| 全期間 | 125 | 54.4% | +0.34% | 1.79 |
| 2005〜10年 | 29 | 48.3% | +0.52% | 2.24 |
| 2011〜14年 | 24 | 41.7% | +0.12% | 1.22 |
| 2015〜18年 | 22 | 63.6% | +0.34% | 1.84 |
| 2019〜21年 | 13 | 76.9% | +0.54% | 3.51 |
| 直近5年 | 37 | 54.1% | +0.26% | 1.60 |

サインは年に5〜6回。22年のうち8年は負け。

1時間ごとに判定する形（2024年8月〜・DMM の取引時間だけ・出口は入った1週間後）: 19回・勝率53%・1回平均 +0.27%・PF1.66。

資金全体での増減（1回のリスク＝資金の2%・単利）: 22年で +19%・最大の落ち込み −8%。大きく増やす道具ではない。損を限定し、検証上わずかに有利だった場面だけを拾う作り。

値は 2026-10-31 に手元で計算したもの。画面の値は自動の計算のたびに計算し直される。
