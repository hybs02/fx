# FX シグナル

11 通貨ペアの RSI を1時間ごとに計算し、決めた規則に当たったペアを「サイン」としてスマホに出す個人用ツール。
DMM FX で手で取引する前提で、入る時刻・損切りの幅・手仕舞う時刻を表示する。API キーは要らない。

画面: https://hybs02.github.io/fx/ （開いて「ホーム画面に追加」）

売買を勧めるものではない。下の成績は過去データでの検証で、この先の成績を示すものではない。必ず勝てる方法は無く、使うかどうかは自分で判断する。

## 使い方

| やること | 方法 |
| --- | --- |
| 見る | 上の画面を開く。1時間ごとに判定し直した結果が出る |
| 今すぐ計算し直す | GitHub の Actions タブ →「update-signals」→ Run workflow |
| 手元で計算する | `python build.py`（標準ライブラリだけで動く） |
| 手元で保存データから作る | `python build.py --cache`（`research/cache/` を使う・動作確認用） |
| 相場の状況・発表日程を直す | `fundamentals.json` を手で書き換えて main に push |

## しくみ

```
GitHub Actions（毎時 3・23・43 分／日〜金 UTC）
  └ build.py が Yahoo から 11 ペアの 1時間足（730 日）と日足（2004 年〜）を取る
      └ いまの値でサイン・損切り幅・次の1時間のサイン価格・検証成績を計算して data.json を作る
          └ data.json は「data」枝に毎回上書き（force push）
              └ 画面は raw.githubusercontent.com/hybs02/fx/data/data.json を読んで表示するだけ
```

- 1時間に3回起動する。GitHub の定時実行は混むと遅れたり飛ばされたりするので、1時間に1回は必ず新しくなるようにしている（us-stocks で測ると3分の1が起動せず、起動しても中央値2時間遅れ）。
- data.json を main に置かない（毎時コミットすると main の履歴が膨らみ続ける）。
- 取れなかったペアは data 枝の前回の値で埋める。前回の値も無ければ失敗で止まる。
- 対象: USDJPY・EURJPY・GBPJPY・AUDJPY・NZDJPY・CADJPY・CHFJPY・EURUSD・GBPUSD・AUDUSD・EURGBP。

## 規則（ツールがサインを出す決まり）

| 項目 | 内容 |
| --- | --- |
| サイン | RSI(14) が 25 以下に入った最初の時刻を買い、75 以上に入った最初の時刻を売りとする。1時間ごとに「その時刻で締めた日足（24時間ごと）」で判定 |
| 同じ山 | 同じ向きの越えが5日以内にあった時は、新しいサインにしない |
| 入る時刻 | サインから3時間以内が目安、8時間を過ぎたら見送り。早朝5〜9時はスプレッドが広いので、締め切りに間に合えば9時を待つ。DMM の取引時間外（土曜 5:50〜月曜 7:00）のサインは入らない |
| 損切り | 入った値から ATR(14)×3 の逆指値。利確は置かない |
| 手仕舞い | 入った時刻の1週間後。取引時間外に当たる時は、その前で最後に取引できる時刻 |
| 持つ数 | 1 ペア 1 ポジション。同じ通貨に同じ向きの取引は2つまで（例: ユーロ円買いとポンド円買いはどちらも円売り） |
| 介入警戒 | ドル円は 160 円の手前 2 円から買いのサインを止める（`fundamentals.json` の `pairAlerts`） |

値は `logic.py`（`BUY_AT`・`SELL_AT`・`SL_ATR`・`HOLD`・`ENTRY_BEST_H`・`ENTRY_LIMIT_H`・`MAX_SAME_SIDE`）と `index.html` にある。

## 検証（research/）

`python research/fetch.py` で `research/cache/` にデータを取ってから各スクリプトを実行する。

| スクリプト | 中身 |
| --- | --- |
| `fetch.py` | Yahoo の日足・60分足、ECB の参照レートを取る |
| `common.py` | キャッシュの読み込みと集計 |
| `study_baseline.py` | 朝9時締めに並べ直した日足で、点数型の判定を22年分測る |
| `study_search.py` | 5つの型 × 出口の組み合わせから、どの時代でも崩れない規則を選ぶ |
| `study_rsi.py` | 選んだ RSI 規則の周辺の設定・ペア別・年別 |
| `study_delay.py` | 入るのが遅れた時の成績（1時間足） |
| `study_cut.py` / `study_cut_fred.py` | 判定の時刻を変えた時の成績（ECB・FRB の公表レート、1時間足から作る24通りの締め時刻） |
| `study_real.py` | 大きな遅れ・スワップ・早朝のスプレッド |
| `study_portfolio.py` | 同時に持つ数と資金の落ち込み |
| `verify_rule.py` | `logic.py` と検証スクリプトが取引1件ずつ一致するか |
| `verify_rolling.py` | `logic.py` の時刻に縛られない版と `study_cut.py` の比べ（取引時間外と出口の扱いが違うので一致はしない） |
| `check_js.py` | 点数型の判定の JS 版（`legacy_index_20260908.html`）と `legacy_logic.py` が一致するか。`python research/check_js.py research/legacy_index_20260908.html` |
| `legacy_logic.py` | 点数型の判定（比較用） |

### 規則を決めた根拠

| 決めたこと | 根拠 |
| --- | --- |
| 日足は「朝9時締め」に並べ直して使う（`logic.make_bars`） | Yahoo の為替日足は 2010 年 6 月ごろから、終値が「その日の UTC 0 時＝日本の朝9時の値」で、高値・安値はその日1日ぶん。そのまま使うと入った日の値動きを飛ばし、その日の値幅を先読みする |
| 点数型の判定（RSI・ボリンジャー・移動平均・MACD の点数）は使わない | 勝つのは直近5年だけ（PF1.59）で、22年通算は PF1.03。ECB のレートで回すと時刻が違い、成績も別物になる |
| 規則は型を並べて選ぶ | 採点・RSI・RSI(2)・高値安値ブレイク・モメンタムの5つの型（設定違いで計25本）× 出口 32 通り＝800 通りを、2004〜2018 年だけで選び、2019 年以降で確かめる。基準は3つの時代の PF の最小値。設計期間の取引が150回以上ある 608 通りの中で、点数型の判定は 496 位（`study_search.py`・2026-09-26 に再実行して確認） |
| RSI(14) 25/75・ATR×3・1週間 | しきい値 20〜30、損切り 2〜4、期限 3〜7 日の周辺もほぼすべて勝ち越し（1点だけの当たりではない）。サイン2日目に入ると PF1.11、3日目は 1.00 で、効くのは初日だけ |
| 入るのは3時間以内、8時間で締め切り | 朝9時締めでは3時間後まで変わらず、9時間以上遅れると悪化（`study_delay.py`）。1時間ごとの判定での遅れは下の表 |
| ペア別の見送りはしない | ペアごとの過去成績は次の期間を当てられなかった（順位相関ほぼ 0） |
| 判定の時刻を固定しない | ECB（欧州の昼）・FRB（NY の昼）の公表レートでも22年通算は勝ち越し（下の表） |
| スワップは判定に入れない | DMM の現在値で1週間ぶん、買い +0.017%・売り −0.014% でほぼ影響なし |
| 早朝5〜9時は9時を待つ | 早朝に入る・出る取引は 89 回中 6 回で、9時まで待つとわずかに良い |
| 同じ通貨・同じ向きは2つまで | サインは同じ日に固まって出る（22年で半分以上が、同じ通貨・同じ向きの取引を持っている最中に出た）。1回のリスクだけ決めて全部入ると、同じ動きで損が重なる（下の資金の表） |

1時間足の大きな足（2024-04-29・05-01 の介入、2025-04-09 の関税停止など）は実際の出来事で、データの誤りではない。

### 成績（過去データ・スプレッド込み・11 ペア合算）

1時間ごとに判定する形（2024年7月〜・DMM の取引時間だけ・出口は入った1週間後・`study_cut.py`）。値は手元の data.json（2026-09-23 20:59 更新）で、画面の値は毎時計算し直される。

| 回数 | 勝率 | 1回平均 | PF |
| --- | --- | --- | --- |
| 86 | 64% | +0.32% | 1.92 |

入るのが遅れた時の PF（同じ条件）:

| 遅れ | 0 | 2時間 | 3時間 | 6時間 | 8時間 | 12時間 | 24時間 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| PF | 1.92 | 1.89 | 1.74 | 1.64 | 1.49 | 1.42 | 1.00 |

1時間足は約2年分しか取れないので、長い期間は日足で確かめる。

判定の時刻を変えた時（22年・日足・終値だけの近似）:

| 判定する時刻 | 通算PF | 2004-10 | 2011-14 | 2015-18 | 2019-26 |
| --- | --- | --- | --- | --- | --- |
| 朝9時（Yahoo） | 1.51 | 1.66 | 1.21 | 1.55 | 1.55 |
| 欧州の昼 14:15（ECB） | 1.23 | 1.23 | 1.11 | 1.12 | 1.37 |
| NYの昼（FRB） | 1.21 | 1.71 | 0.83 | 1.30 | 1.00 |

どの時刻でも通算は勝ち越し。朝9時が一番安定。

朝9時締めの日足（2005〜2026・DMM の公式スプレッド込み）:

| 期間 | 回数 | 勝率 | 1回平均 | PF |
| --- | --- | --- | --- | --- |
| 全期間 | 564 | 52.5% | +0.22% | 1.34 |
| 2004〜10年 | 141 | 54.6% | +0.27% | 1.35 |
| 2011〜14年 | 122 | 43.4% | +0.11% | 1.17 |
| 2015〜18年 | 108 | 51.9% | +0.30% | 1.60 |
| 2019〜21年 | 79 | 60.8% | +0.16% | 1.21 |
| 直近5年 | 114 | 54.4% | +0.25% | 1.43 |

日足で見ると22年のうち7年は負け。サインは1時間ごとの判定で月に3回ほど。

資金全体での増減（1回のリスク＝資金の2%・単利・`study_portfolio.py`）:

| 期間 | 同じ向き2つまで：増減 | 同：最大の落ち込み | 全部入った場合の落ち込み |
| --- | --- | --- | --- |
| 2024年7月〜（1時間ごと） | +21% | −6% | −10% |
| 2005〜2026（日足） | +42% | −21% | −28% |

大きく増やす道具ではない。損を限定し、検証上わずかに有利だった場面だけを拾う作り。
