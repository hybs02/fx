# 📈 FX シグナル判定ツール

スマホのブラウザで開くだけで使える、FX（為替）の売買シグナル判定ツールです。
アプリのインストール不要・無料・単一HTMLファイルで動きます。

**▶ 使う： https://hybs02.github.io/fx/**

スマホで開いたら、ブラウザの「ホーム画面に追加」をしておくと1タップで起動できます。

## できること

- **全ペア一括チェック**（APIキー不要）… 11通貨ペアの日足シグナルを一覧表示。サインが出ているペアがすぐ分かる
- **売買シグナル判定** … 日足を主軸に、RSI・ボリンジャーバンドの「行きすぎ→反発」を主力とした判定（8時間足・4時間足はタイミング確認用）
- **利確・損切りの目安を常に表示** … ATRベース（SL/TP = 2.0/2.0、リスクリワード1:1）。OCO注文にそのまま使える価格を提示（APIキー無しでも概算で表示）
- **資金管理（推奨ロット自動計算）** … 資金とリスク%を入れると、損失が資金の指定%に収まるロット数を自動計算
- **重要イベントの自動警告** … FOMC・日銀会合・米雇用統計が近づくと警告を表示。値が飛ぶ前のエントリーを防ぐ
- **過去5年の勝率を正直に表示**（APIキー入力時）… 全期間の成績に加え、設定選びに使っていない直近期間（本番想定）の成績を併記

## 使い方

1. 上のURLをスマホで開く
2. 通貨ペアのボタンを押す（または「全ペアを一括チェック」）
3. 判定・勝率・利確損切り・推奨ロットを確認
4. エントリーする場合は、表示された価格でOCO注文（利確＋損切り）を置く

※ 8時間足・4時間足まで見たい場合は、[Twelve Data](https://twelvedata.com/register) の無料APIキー（メール登録のみ）を上部の欄に入力してください。キー無しでも日足の判定・一括チェックは使えます。

## 判定ロジックについて

- 過去5年・7通貨ペアの実データでバックテストし、**実際に勝てた条件だけ**を採用しています
- 検証の結果、移動平均・MACDなどの順張り指標は単体では優位性がなく、RSI・ボリンジャーの逆張りが利益源だったため、逆張り主軸の重み付けにしています
- サインが出る回数は少なめですが、それが仕様です（質の高いサインだけに絞っています）
- データソース：Twelve Data（キー入力時）／ frankfurter・ECB日次（キー無し時）
